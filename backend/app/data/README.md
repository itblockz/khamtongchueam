# Data

`word_hints.json` holds what the judge's hints use (`backend/app/hints.py`). It is
generated by `backend/benchmarks/build_word_hints.py`; do not edit it by hand.

- `notNoun`: words the dictionaries know with no noun sense
- `gloss`: Thai word → English meanings

Sources and licences:
- English Wiktionary's Thai entries, via [kaikki.org](https://kaikki.org/dictionary/Thai/)
  (CC BY-SA 4.0); the derived `gloss` data is under the same licence.
- [PyThaiNLP](https://github.com/PyThaiNLP/pythainlp) corpora: Thai Wiktionary
  dictionary, Thai WordNet and the ORCHID / UD / TDTB part-of-speech tables; see PyThaiNLP's
  [corpus licences](https://github.com/PyThaiNLP/pythainlp/blob/dev/pythainlp/corpus/corpus_license.md).

The Thai-English transliteration table is not copied here: `hints.py` reads it from the
installed PyThaiNLP package.
